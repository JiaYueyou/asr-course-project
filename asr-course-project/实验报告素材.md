## 二、代码模块与函数功能

### 2.1 dataset.py —— 数据与特征
| 函数/类 | 功能 |
|---|---|
| `extract_mel_spectrogram` | librosa 提取 log-mel：25ms 窗 / 10ms 步 / 512 点 FFT / 80 mel / 80–7600Hz，log10 压缩动态范围，输出 [T, 80] |
| `normalize_features(f, stats)` | CMVN 归一化；stats 给定时用全局统计量（本项目方案），否则逐条 |
| `Vocabulary` | 字符级词表：`add_text` 收录字符、`encode/decode` 编解码、`save/load` JSON 持久化；修复了集外字符 KeyError 问题 |
| `SpeechDataset` | 读 manifest（`文件名 文本`）→ `_load_audio`（soundfile，16kHz 单声道）→ 提特征 → 20s 截断 → **全局 CMVN**（`compute_global_stats` 遍历训练集统计 mean/std）→ 文本编码 |
| `collate_fn` | 变长组批：特征 padding 到 batch 最大 T，`input_lengths/label_lengths` 记录真实长度 |
| `create_dataloader` | 封装 DataLoader（collate_fn、shuffle、num_workers） |

### 2.2 model.py —— 网络（DeepSpeech2）
| 模块 | 配置 |
|---|---|
| `input_fc` | Linear(80→128) + ReLU + Dropout(0.2) |
| `lstm` | **5 层双向 LSTM**，hidden=128（双向拼接 256），层间 dropout |
| `output_fc` | Linear(256→128) + ReLU + Dropout + Linear(128→**29**) |
| 输出 | `log_softmax`，配合 CTCLoss |
| `forward` | `pack_padded_sequence`（跳过 padding 帧）→ BiLSTM → `pad_packed` → 输出 (log_probs, output_lengths) |
| `_init_weights` | Xavier uniform 初始化 |
| 参数量 | **1,892,253**（hidden=128 时） |

### 2.3 train.py —— 训练
| 函数/类 | 功能 |
|---|---|
| `CTCLossWrapper` | CTC 损失封装：log_probs 转 [T,B,C]、targets 截断 padding、`zero_infinity=True` 防长度约束溢出 |
| `WarmupScheduler` | 学习率线性 warmup |
| `train_epoch / validate` | 单 epoch 训练/验证循环（AMP 混合精度、梯度裁剪 clip=5.0） |
| `main` | 词表加载（优先读 vocab.json 文件）→ 数据加载 → **全局 CMVN 统计** → AdamW 训练 → checkpoint 保存（含模型权重、词表、**CMVN 统计量**，保证推理端归一化与训练同源） |

### 2.4 inference.py —— 推理
| 函数/类 | 功能 |
|---|---|
| `SpeechRecognizer.__init__` | 从 checkpoint 恢复模型、词表、**CMVN 统计量** |
| `extract_features` | 与训练完全相同的特征参数提取 + 同一组全局 CMVN（消除训练/推理分布不一致） |
| `recognize` | greedy（逐帧 argmax→合并连续重复→删 blank）或 beam search 解码 |

### 2.5 cer.py —— 评估
| 函数 | 功能 |
|---|---|
| `compute_cer` | 单条 CER：Levenshtein 编辑距离，返回 (S 替换, D 删除, I 插入) |
| `compute_cer_corpus` | 语料级 CER = Σ(S+D+I)/ΣN（不做逐条平均，避免短句权重失真） |

### 2.6 run_demo.py（重写）与 prepare_timit.py（自研）
- `run_demo.py`：真实 TIMIT 数据端到端演示——词表加载 → 全局 CMVN → 训练（warmup + AdamW）→ `quick_eval` 训练期 CER 监控 → SpeechRecognizer greedy 推理 → 语料级 CER 报告；
- `prepare_timit.py`：TIMIT → asr 格式转换（选取规则见下节）。

## 三、数据集选择与准备

### 3.1 选型
| 项 | 内容 |
|---|---|
| 数据集 | **TIMIT**（Apache-2.0 开放镜像），英文朗读语音 |
| 全量规模 | 6,300 句 / 630 说话人 / 16 kHz 单声道 / 每句配 TXT 文本标注 |
| 选择理由 | 标准语音研究语料、标注规整、英文场景下字符级 CTC 词表极小（29 类），适合小规模算法链路复现 |

### 3.2 选取规则（prepare_timit.py，共 50 条）
1. 仅取 TRAIN 划分；排除 SA1/SA2 固定句（630 人重复朗读，不利于词汇多样性）；
2. 说话人集中：10 个说话人 × 每人 5 条（说话人 FCJF0…FSJK1）；
3. 时长 2–8 s、文本 20–150 字符；
4. 硬校验 CTC 长度约束 **T ≥ 2L+1**（帧数 ≥ 2×字符数+1），50/50 全部通过。

### 3.3 数据统计
| 指标 | 数值 |
|---|---|
| 音频总量 | 2.7 分钟（50 条），时长 2.07–5.57 s |
| 帧数 T（100 fps） | 205 – 555，均值 320 |
| 字符数 L | 27 – 78，均值 49 |
| T/L 比 | ≥ 4.7（CTC 约束 2.0 的两倍余量） |
| 词表 | **29 类 = blank(0) + 26 字母 + 空格 + 撇号** |
| CMVN 统计 | 16,118 帧 × 80 维（训练集全局） |

## 四、实验结果整理与分析

### 4.1 实验配置演化
| 配置项 | 实验 1（初版） | 实验 2（当前） |
|---|---|---|
| 数据 | TIMIT 50 条 | 同左 |
| epoch | 60 | 150 |
| lr | 1e-3，无 warmup | **5e-4 + 线性 warmup 100 步** |
| hidden / dropout | 128 / 0.2 | 128 / 0.2（同） |
| 参数量 | 1,892,253 | 同 |

### 4.2 实验 1：CTC 塌缩到全 blank（CER = 100%）
- **现象**：loss 从 12.28 骤降至 2.98（≈ln 29=3.37 下方）后横盘；greedy 解码全部为**空串**；错误构成 100% 为删除（2,460/2,460）。
- **分析**：正确答案中 ~85% 的帧本应为 blank，"每帧都输出 blank"是损失面上宽而稳的局部最优（**blank 塌缩**）；lr=1e-3 无 warmup 使模型在前 70 步直接落入该盆地，且总步数仅 420，无法逃逸。
- **处理**：降低 lr 至 5e-4、加 100 步线性 warmup、延长训练至 150 epoch，并加入训练期 CER 监控。

### 4.3 实验 2：逃逸塌缩，进入慢速收敛（CER = 84.47%）
| Epoch | Loss | 训练集 CER | 样例识别输出 |
|---|---|---|---|
| 1 | 18.16 | 93.98% | `xhxjxxjuxxzxxx`（未塌缩，乱字符） |
| 10–80 | 3.04 → 2.90 | 100%（空串） | 二次进入 blank 主导区 |
| 100 | 2.78 | 97.97% | `te`（首批字符出现） |
| 130 | 2.17 | 96.91% | `ctr` |
| 150 | **1.53** | **84.47%** | ` th     ctcer` |

- **错误构成**（epoch 150）：2,078 错误 = **2,072 删除 + 6 替换 + 0 插入**；
- **分析**：
  1. loss 在 epoch 90 后加速下降（2.92→2.78→2.62→2.40→2.17→1.78→1.53），模型已逃逸全 blank 盆地，字符开始成段出现；
  2. 错误以**删除为主**（99.7%）——即模型输出的字符数远少于参考文本，是 CTC 训练中期的典型形态：字符发射概率峰尚未锐化，大量字符仍被 blank 覆盖；
  3. 150 epoch（1,050 步）对"320 帧序列对齐 49 字符 + 5 层 LSTM"的任务总量仍偏少，收敛处于爬坡中段而非平台。

### 4.4 实验过程中修复的三个关键问题
| 问题 | 现象 | 根因 | 修复 |
|---|---|---|---|
| 词表为空 | 中文合成 demo CER=100% | 构建词表后从未调用 `add_text`，所有字符编码为 UNK | 换真实数据 + 29 类语料词表 |
| `KeyError: '<unk>'` | 训练启动即崩溃 | `dict.get(c, d)` 的默认值被无条件求值，封闭词表无 `<unk>` 槽位 | 重写 `encode`：无 UNK 时集外字符显式报错 |
| blank 塌缩 | loss 横盘 ~2.9、解码全空 | 大 lr 无 warmup + 步数不足 | warmup 100 步 + lr 5e-4 + 延长训练 |

### 4.5 结论与下一步方向
**结论**：数据管线（TIMIT→asr 格式）、特征前端、全局 CMVN 一致化、字符词表、CTC 训练与 greedy 解码、CER 评估的完整链路已打通并逐步收敛；当前模型处于塌缩逃逸后的字符锐化阶段，CER 随训练持续下降，链路正确性得到验证。

**下一步（已分析、未执行）**：
1. 增大模型容量（hidden 256）+ 遗忘门偏置初始化 1.0（加速深层记忆通路）；
2. 学习率余弦退火 + 延长至 400 epoch；
3. 进一步可做：帧拼接降帧率（缩短 CTC 对齐序列）、前缀束搜索解码对比。
